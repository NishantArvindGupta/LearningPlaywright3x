# Source Code vs Bytecode vs Binary Code

## Exam-Style Quick Revision Notes

### Example

```javascript
console.log("Hello, Nishant Gupta welcome to the world of JavaScript with Testing Academy!");
```

This line is written in JavaScript source code and stored in a `.js` file.

---

## Difference Between Source Code, Bytecode, and Binary Code

| Type | Definition | Human-readable | Executed by CPU directly? |
|------|------------|----------------|--------------------------|
| Source code | Original program written by the programmer | Yes | No |
| Bytecode | Intermediate code generated by the interpreter/compiler | Not easily | No |
| Binary code | Machine-level instructions understood by the CPU | No | Yes |

---

## 1. Source Code

- Written by the developer in a programming language such as JavaScript, Python, or Java.
- Easy for humans to read and modify.
- Example: `console.log(...)` in JavaScript.
- It is not directly understood by the CPU.

---

## 2. Bytecode

- Produced from source code by the interpreter or compiler.
- It is a middle-level representation.
- It is more machine-friendly than source code but not the final CPU instructions.
- In JavaScript, the engine may generate bytecode internally before execution.

---

## 3. Binary Code

- The final machine instructions that the CPU understands.
- Stored in executable form as 0s and 1s.
- This is the code that actually runs on the machine.

---

## Execution Flow

```text
Source code
    ↓
Bytecode
    ↓
Binary / machine code
    ↓
CPU executes it
```

---

## Short Exam Answer

Source code is the original human-written program. Bytecode is an intermediate code generated by the runtime or compiler for efficient execution. Binary code is the final machine-readable instructions that the CPU executes directly. In JavaScript, code usually goes from source code to bytecode and then to machine code during execution.

---

## Very Short Revision Point

```text
Source code = human written
Bytecode = intermediate code
Binary code = machine executable code
```

---

## Final Summary

JavaScript code begins as source code, is converted into bytecode by the JavaScript engine, and then further translated into binary instructions that the CPU runs. Thus, source code is readable by humans, bytecode is an internal runtime format, and binary code is the final executable form.
